# specs — спецификация проекта

Главные документы проекта. Код — производное от них: изменение начинается здесь, и правка документа идёт **тем же коммитом**, что и правка кода.

| Файл | Что внутри | Кто утверждает |
|---|---|---|
| `STATUS.md` | **Читать первым в каждой новой сессии:** этап, что сделано, что ждём и от кого, следующий шаг | — (агент обновляет в конце каждой сессии) |
| `requests.md` | Один список запросов клиенту: доступы, ассеты, вопросы — с пометкой «блокирует этап N» и полем ответа | Ник отправляет |
| `decisions.md` | Решения проекта: «нет цен», «клиентов не называем», фирменные формулировки — их же забирает `/content` | Ник |
| `changes.md` | Журнал изменений объёма: каждая порция правок — «+N часов, срок держится / нет», новые строки снизу | Ник, клиент |
| `00-brief.md` | Бриф: факты о клиенте (предзаполнен из открытых источников) | Ник |
| `00-transfer-audit.md` | Только перенос: анализ старого сайта, инвентаризация, медиа, карта редиректов | Ник |
| `01-research.md` | Конкуренты, семантика, пул GEO-запросов | Ник |
| `01-transfer-proposals.md` | Только перенос: пожелания и предложения, вариант объёма | Клиент |
| `02-spec.md` | **Что строим** — только текущее состояние, без истории | Клиент |
| `03-design.md` | Дизайн-система, иконки, токены, прототипы, заморозка стиля | Клиент |
| `04-plan.md` | Как spec ложится на код, хостинг и способ выкладки | Ник |
| `05-tasks.md` | Задачи агента со статусами и журналом | Ник |
| `06-launch-checklist.md` | Ручная проверка: «блокирует выкладку» и «после выкладки» | Ник |
| `reports/` | Отчёты `npm run check`, geo-check «до» и «после», `baseline/` — экспорт Метрики и Вебмастера до переезда | — |

Шаблоны лежат в NikitOS: `Resources/Frameworks/AI-Ready сайт — шаблоны/`. Скилл `new-site` / `transfer-site` копирует их сюда при старте проекта.
Требования, которые действуют всегда, — `Resources/Frameworks/AI-Ready сайт — стандарт.md`.
